# PSet 4 · Proyecto final

**Priorización diaria de la cartera de autos en cobranzas**

Ciencia de Datos · Maestría en Ciencia de Datos (USFQ) · Jennifer Stephania Cárdenas Jácome

Cada día el call center puede hacer 600 llamadas. Un modelo estima la probabilidad de que cada crédito en mora pague en 7 días y arma la lista por monto esperado a recuperar. En la simulación de 18 lotes diarios, la lista del modelo captó **52 % más pagos** que la regla actual (mayor capital primero).
